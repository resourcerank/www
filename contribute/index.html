Open Participation

Contribute to ResourceRank

ResourceRank is maintained as an open Git-backed static registry. Every evaluation and decision record is peer-reviewed via pull request before publication.

Submission Workflow

01

Gather Verifiable Evidence

Collect immutable links, cryptographic release hashes, benchmark DOIs, and SPDX license identifiers for the target resource.

02

Author YAML Frontmatter

Create a Markdown record in _evaluations/ or _decisions/ conforming to the schema below.

03

Peer Review & Consensus

Working group reviewers validate score calculations, verify artifact hashes, and merge approved records into the public build.
